Installer l’extension Statistiques

Chaque joueur effectue cette installation une seule fois dans son propre profil Chrome ou Edge.

  1. Télécharger l’extension puis décompresser le ZIP dans un dossier permanent.
  2. Ouvrir chrome://extensions dans Chrome ou edge://extensions dans Edge.
  3. Activer Mode développeur, choisir Charger l’extension non empaquetée et sélectionner le dossier contenant manifest.json.
  4. Revenir à Build Analyzer, recharger la page, se connecter à son compte puis ouvrir Statistique.
  5. Cliquer sur Connecter mes statistiques. Si une connexion est nécessaire, utiliser le lien Se connecter à Behaviour, puis se connecter au compte de ce joueur sur le site officiel. Cet onglet peut ensuite être fermé.

L’extension transmet la première connexion au serveur. Les jetons Behaviour sont conservés chiffrés dans Supabase Vault et renouvelés automatiquement ; les mots de passe et cookies restent dans votre navigateur. Après confirmation du transfert, l’extension efface sa copie des jetons.

Le serveur synchronise ensuite toutes les cinq minutes, même navigateur fermé et PC éteint. La synchronisation n’ouvre aucun onglet. Une reconnexion reste nécessaire si Behaviour révoque ou expire son autorisation.

Sur un ordinateur partagé, chaque joueur doit utiliser un profil Chrome ou Edge distinct. Un profil de navigateur est associé à un seul compte Build Analyzer à la fois.

Behaviour peut expirer ou révoquer sa session : une reconnexion au site officiel sera alors nécessaire. L’extension ne modifie pas cette règle.

Pour arrêter la collecte et supprimer les jetons du serveur, utiliser Désactiver la synchronisation dans le site. Se déconnecter ou désinstaller l’extension laisse la collecte distante active.

Pour mettre l’extension à jour, remplacer les fichiers du dossier puis cliquer sur Recharger. La version 0.3.0 transfère automatiquement la connexion déjà conservée par la version 0.2.0. Si nécessaire, reconnecter Behaviour depuis le site.
