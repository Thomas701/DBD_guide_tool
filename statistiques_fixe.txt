# 16. Comment interpréter les « +X % » des perks

C'est **très important pour ton application**, car tous les pourcentages ne veulent pas dire la même chose.

### A. Vitesse d'action

Si une action prend normalement `T` secondes et qu'on augmente sa **vitesse** de +X %, on ne retire pas simplement X % au temps.

La formule simple pour un modificateur isolé est :

**nouveau temps = temps de base / (1 + bonus)**

Exemple : soin de 16 s avec **+50 % de vitesse** :

`16 / 1,5 = 10,67 s`

et **pas 8 secondes**.

C'est exactement pourquoi un Ranger Med-Kit à +50 % soigne en ≈10,67 s. ([Dead by Daylight Wiki][7])

### B. Durée

Si une perk dit :

**« dure 50 % plus longtemps »**

alors :

`durée finale = durée initiale × 1,5`

Exemple : 10 s → **15 s**.

### C. Probabilité

Lorsqu'un effet comme **Présence perturbante** ajoute **+10 % de probabilité de test d'habileté**, il s'agit de **points de pourcentage** dans ce contexte :

**8 % → 18 %**, et non 8,8 %. ([Dead by Daylight Wiki][6])

### D. Sons / Stridor

Pour les sons, il n'existe pas de valeur universelle utile du style « 53 dB ».

Dans ta base, le plus propre est :

```text
default_grunt_volume = 1.0   // 100 %
stridor_bonus = 0.50         // +50 %
result = 1.50                // 150 %
```

Donc **Stridor +50 % = 150 % du volume relatif normal**.

### E. Vitesse de déplacement

Pour un personnage ayant une vitesse de 4,6 m/s :

`+5 % Haste → 4,6 × 1,05 = 4,83 m/s`

Le **100 % affiché par DBD** correspond historiquement aux **4,0 m/s du survivant**, mais un modificateur de Hâte est appliqué à la vitesse concernée. ([Dead by Daylight Wiki][19])

# 17. Les stats qu'il ne faut PAS mettre en global

Pour ton projet, je séparerais absolument ces données, car elles varient selon le tueur :

| Statistique                    | Où la stocker   |
| ------------------------------ | --------------- |
| Vitesse normale du tueur       | `killer`        |
| Rayon de terreur               | `killer`        |
| Taille : petit / moyen / grand | `killer`        |
| Pouvoir                        | `killer_power`  |
| Vitesse avec pouvoir           | `killer_power`  |
| Cooldowns de pouvoir           | `killer_power`  |
| Portées de pouvoir             | `killer_power`  |
| Durées d'effets du pouvoir     | `killer_power`  |
| Temps de recharge              | `killer_power`  |
| Add-ons                        | `killer_addons` |

En revanche, **3,68 m/s en transport, 1,8 s pour kick un générateur, 2,34 s pour une palette, 1,7 s pour une fenêtre, 2,7 s de récupération après coup, etc.** peuvent parfaitement être rangés dans une table globale de mécanique.

### Structure que je te conseillerais

```text
global_mechanics
    survivor_run_speed = 4.0
    survivor_walk_speed = 2.26
    survivor_crouch_speed = 1.13

    generator_charges = 90
    generator_solo_time = 90
    generator_damage_time = 1.8
    generator_damage_penalty = 0.05
    generator_regression_rate = 0.25

    heal_charges = 16
    altruistic_heal_time = 16
    dying_recovery_time = 30.4
    dying_bleedout_time = 240
    self_mend_time = 10
    altruistic_mend_time = 6

    pallet_break_time = 2.34
    pallet_stun_time = 2.0
    wall_break_time = 2.34
    killer_window_vault_time = 1.7

    hook_time = 1.5
    unhook_time = 1.0
    sabotage_time = 3.0
    sabotaged_hook_respawn = 30
    carry_speed = 3.68
    wiggle_time = 16

    totem_cleanse_time = 14
    dull_totem_bless_time = 14
    hex_totem_bless_time = 28
    boon_snuff_time = 1

    exit_gate_time = 20
    hatch_key_open_time = 2.5

    scratch_mark_lifetime = 10
    flashlight_blind_time = 1
    flashlight_blind_duration = 2
```
