DBD Build Analyzer — Statistiques (Chrome, Edge, Opera et navigateurs Chromium compatibles)
Version 0.4.2

Installation depuis la boutique officielle :
1. Dans le site, ouvrez Statistique et cliquez sur « Installer l’extension et connecter Behaviour ».
2. Confirmez l’installation dans la boutique. Gardez le site ouvert : il détecte l’extension et reprend automatiquement, sans rechargement.
3. Connectez votre compte dans la page officielle Behaviour ouverte si une connexion est nécessaire. L’association et l’activation de la synchronisation se terminent automatiquement.

Chaque joueur utilise son propre profil de navigateur. Une confirmation d’installation du navigateur reste obligatoire. Edge peut demander d’autoriser les extensions provenant d’une autre boutique.

Installation manuelle provisoire, si la fiche n’est pas encore disponible :
1. Décompressez ce ZIP dans un dossier permanent.
2. Ouvrez chrome://extensions, edge://extensions ou opera://extensions.
3. Activez « Mode développeur », choisissez « Charger l’extension non empaquetée » et sélectionnez le dossier contenant manifest.json.
Le site déjà ouvert détecte automatiquement l’extension. Si vous n’aviez pas encore lancé l’association, ouvrez Statistique puis cliquez sur « Connecter Behaviour ».

La synchronisation continue ensuite sur Supabase toutes les cinq minutes, navigateur fermé et PC éteint. Les jetons Behaviour sont conservés chiffrés dans Supabase Vault ; l’extension efface sa copie après confirmation. Les mots de passe et cookies restent sur le site officiel.

Pour arrêter la collecte et supprimer les jetons du serveur, utilisez « Désactiver la synchronisation ». Les parties enregistrées restent conservées. La déconnexion du site et la désinstallation de l’extension seules n’arrêtent pas la collecte distante.

Behaviour peut expirer ou révoquer l’autorisation : une nouvelle connexion sera alors nécessaire. L’extension ne peut pas empêcher cette révocation.

Sur les anciennes versions de Chrome, dont Chrome 126, l’autorisation temporaire utilise le stockage de session privé. Gardez Chrome ouvert jusqu’à l’activation distante ; une fermeture avant confirmation impose de reprendre la connexion. Après activation, la collecte continue sur le serveur.

Les mises à jour de la boutique sont gérées par le navigateur. Pour une installation manuelle, remplacez les fichiers du dossier puis cliquez sur « Recharger » dans la page des extensions ; les onglets déjà ouverts sont activés automatiquement.
